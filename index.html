안전인증 (KC) 대기

AuthKey 헤더 인증이 필요합니다. GitHub Pages 단독 실행은 불가하며 로컬 server.py 또는 별도 백엔드 프록시가 필요합니다.
⚙️ 설정 (프록시 · API 키 · 엔드포인트)
GitHub Pages는 정적 호스팅이라 /fetch가 실행되지 않습니다. 안전인증·RRA 실시간 조회는 반드시 로컬/전용 프록시가 필요합니다.
로컬 실행: /fetch. GitHub Pages 화면에서 로컬 server.py를 같이 쓰려면 http://localhost:8000/fetch.
{url} 자리에 대상 URL 삽입. 공개 프록시는 헤더/AuthKey/POST 전달이 제한됩니다.
HTTP 헤더 AuthKey 로 전송됩니다. GitHub Pages 단독 배포에서는 브라우저만으로 안전하게 처리할 수 없습니다.
RRA 무료 Open API는 인증번호(mtlCefNo)로 조회합니다.
모델명 실시간 조회는 RRA 사이트에 POST 하므로 GitHub Pages 단독 모드에서는 사용할 수 없습니다.
rra_db.json을 index.html과 같은 위치에 두면 GitHub Pages에서도 모델명 검색이 가능합니다.
